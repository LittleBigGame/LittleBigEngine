# Legacy archive: pre-rebuild snapshot

This branch is a frozen archive of the LittleBigEngine repository as it stood
immediately before the greenfield rebuild (snapshot of `main` at commit
`eef7957ea907b6258476f6ac4f34b11568790535`, archived 2026-10-16).

It preserves the previous Python ModEngine kernel prototype, the DearPyGui
editor, the "Example World" data, scratch experiments and all prior
documentation and governance files exactly as they were.

Nothing on this branch is maintained. The new LittleBigEngine implementation
lives on the main development line and does not reuse this code.
Older historical branches (`archive/legacy-engine`, `codex/*`, `feat/*`,
`feature/*`, `fix/*`) are also preserved unchanged.
